# P0 Spike — 固定版心溢出量测语义（预案 + 实测日志）

> 日期：2026-08-07 · Typst 0.15.1 · Python 3.14.4
> 目的：为 presswire 验证「固定版心不推页 + 溢出可测可报」的 Typst 原语可行性，
> 并锁定后续任务（7/11/17）的 API 通道。**本文件是权威结论，勿凭记忆。**

## 一、预案（spike 计划）

### 目标假设（3 个，待验证）

- **H1（固定版心）**：`block(width, height, clip: true, breakable: false)` 可复现 linotype「固定版心不推页」纪律——内容自然高度超出版心时被裁剪，不产生新页面。
- **H2（溢出可测）**：`measure(block(width: W, content)).height` 能返回内容在固定宽度下的**自然高度**，据此可算 fill 比率与 deficit 溢出量；`#metadata` 携带 fill/deficit 后可通过 Typst 查询通道提取。
- **H3（宽度风险）**：即使内容存在**宽度溢出**（内层超宽盒 / 不可换行长串），measure 不报错、不异常撑高，高度量测仍可用——即已知 issue #7779 不阻断本方案。

### 备选路径（若 H2 主路径受阻）

- 深度块测（libver 已证可行）：`measure(block(width: W, content)).height`。
- 仍不通 → 报阻塞，不继续 autofit 类任务。

## 二、实测日志（数值证据）

### 实验 1 — 固定版心不推页 + measure 三测法对比

```bash
typst compile p0-exp1-fixed-box.typ    # → 1 页
typst eval 'query(metadata)' --in p0-exp1-fixed-box.typ --format json
```

| 测法 | 表达式 | 结果 | 说明 |
|---|---|---|---|
| A | `measure(block(width:150pt, height:100pt, clip:true, story))` | **100pt** | ❌ 量的是固定盒自身，无法暴露溢出 |
| B | `measure(block(width:150pt, story))`（深度块测） | **1092.22pt** | ✅ 自然高度 |
| C | `measure(story, width:150pt)`（width 参数法） | **1092.22pt** | ✅ **同值，且最简洁——选型 C** |

- `deficit = 1092.22 - 100 = 992.22pt`；`fill = 100/1092.22 = 0.0916`；`overflow-detectable = true`
- 页数：**1 页**（固定盒 + footer 后仍单页）→ **H1 成立**

### 实验 1b — 对照：自动高度 → 推页

```bash
typst compile p0-exp1b-push.typ    # → 5 页
```

- `block(width:150pt)` 无高度约束 + breakable 默认 → 内容按页流动，**5 页**。
- 反证：**H1 的「不推页」来自固定 height，而非偶然**。✅

### 实验 1c — 对照：固定高度 + 无 clip → 仍不推页

```bash
typst compile p0-exp1c-spill.typ    # → 1 页
```

- `block(width:150pt, height:100pt, breakable:true)` 无 clip → **1 页**，溢出内容与后续对照线重叠（页内溢出可见）。
- 结论：**固定高度本身即阻止推页；clip 只决定溢出可见/隐藏**。溢出报告能力（H2）与视觉裁剪（clip）解耦——presswire 可分别控制。

### 实验 2 — 查询通道：eval 取代 query，label→metadata 关联成立

```bash
# 旧通道（弃用，仅告警仍可用）：
typst query p0-exp2-query.typ "<plate-P1>" --format json
# 新通道（推荐）：
typst eval 'query(<plate-P1>)' --in p0-exp2-query.typ --format json
```

- `typst query` 输出**弃用警告**，提示改用 `typst eval 'query(...)' --in ...`——两者输出等价。
- **label 附着 metadata 模式**（`#metadata((...))` 后紧跟 `#label("meta-P1")`）：
  `query(<meta-P1>)` 返回 `{"func":"metadata","value":{plate,fill,deficit,overflow},"label":"<meta-P1>"}` —— **完整 value 直接可查，无需字段提取**。✅
- label 打在 block 上则返回 block 结构（无 value 字段），value 需另走 `query(metadata)`。
- **选型：label 直接打 metadata，`typst eval 'query(<label>)'` 取 value。** 这是最干净通路。

### 实验 3 — CJK 中文长文：同样不推页、可测

```bash
typst compile p0-exp3-cjk.typ    # → 1 页（中文字体 Noto Serif CJK SC, lang: zh）
```

- 自然高度 **545.1pt**（150pt 宽），deficit **445.1pt**，fill **0.183**，overflow-detectable = true。
- **N1 前置验证通过**：中文与拉丁在固定版心 + measure 语义上行为一致，无 CJK 特例。

### 实验 4 — 宽度溢出风险边界（#7779 阻断解除）

| 场景 | 输入 | measure 结果 | 结论 |
|---|---|---|---|
| A | 150pt 约束内放 300pt 宽内层盒 | height=30pt，不报错 | 宽度溢出被约束，高度量测不受影响 |
| B | 不可换行长串（56 个 W） | height=6.58pt（单行），width 被约束为 150pt | 未返回自然宽，但**不报错、可量高** |
| C | 正常文本对照 | height=45.82pt | ✅ |
| D | 无约束溢出盒 | width=300pt（自然宽） | 无约束时自然宽可测 |

- **H3 成立**：宽度溢出场景下 measure 全部安全（无报错、无异常撑高）。#7779 不阻断本方案。

## 三、结论（假设判定 + API 决策）

### 假设判定

| 假设 | 判定 | 证据 |
|---|---|---|
| H1 固定版心不推页 | ✅ 成立 | exp1 单页 + exp1b 5 页对照 |
| H2 溢出可测可报 | ✅ 成立 | exp1/exp3 数值可算；exp2 通道可用 |
| H3 宽度风险不阻断 | ✅ 成立 | exp4 全部场景安全 |

**P0 阻塞解除。** 任务 7/11/17 可按本文件结论推进。

### API 决策（后续任务直接采用）

1. **固定版心原语**：`block(width: W, height: H, clip: true, breakable: false)`。
2. **溢出量测**：`measure(content, width: W).height`（测法 C，宽度参数法）——简单且与深度块测同值；特殊内容（如无宽度参数可传的布局）退回 `measure(block(width: W, content)).height`。
3. **溢出报告通道**：`#metadata((fill: ..., deficit: ...))` + `#label("<plate-id>")` 相邻；`typst eval 'query(<plate-id>)' --format json` 取 value。**禁用** `typst query`（弃用）。
4. **clip 与报告解耦**：视觉裁剪 `clip: true` 常开；溢出报告走 metadata 独立通道，二者互不依赖。
5. **CJK 无特例**：同一原语处理中文内容，字体走 `#set text(font: ..., lang: "zh")`。
6. **fill/deficit 公式**：`natural = measure(...).height`；`deficit = natural - H`（正=溢出）；`fill = calc.min(H / natural, 1.0)`。

### 遗留风险（非阻塞）

- `measure(story, width:)` 对**无宽度参数可传的复杂布局**（grid/columns 组合体）的适用性未覆盖——任务 7 模板装配时若遇到，退回深度块测即可。
- metadata 内**长度字段在 JSON 中序列化为字符串**（如 `"992.22pt"`）——下游 Python 解析需转数值（`float(x.replace("pt",""))`），任务 17 注意。
