# 实验 J — Typst 转义规则实测（任务 5 render_typst 前置）

> 日期：2026-08-07 · Typst 0.15.1 · 源文件：`/tmp/typst-r1/esc-code.typ` 等

## 问题

linotype 有成熟的 `tex_escape`（占位符防二次转义等血泪）。presswire 换 Typst 转义——**哪些字符需要转义、怎么转**？计划只写了"反引号/`$`/`<`/`>`"是推测，可能漏字符。

## 实测结果

### 1. markup 模式（反斜杠转义生效）

| 输入 | 渲染 | 说明 |
|---|---|---|
| `\$` | `$` | ✅ 转义生效 |
| `\#` | `#` | ✅ 转义生效 |
| `\[x\]` | `[x]` | ✅ 转义生效 |
| `\*x\*` | `*x*` | ✅ 转义生效 |
| `\_x\_` | `_x_` | ✅ 转义生效 |
| `\<x\>` | `<x>` | ✅ 转义生效 |
| `\{x\}` | `{x}` | ✅ 转义生效 |
| `\u{5C}` | 字面 `\u{5C}` | ❌ **markup 里码点转义不解析**（需 code/字符串内） |

**结论**：markup 模式反斜杠转义全套生效（`$ # [ ] * _ < > { }` 均需转义）。

### 2. code 模式字符串字面量（几乎无需转义！）

| 字符串内容 | 渲染 | 说明 |
|---|---|---|
| `"美元 \$ 井号 \# ..."` | `\$` 保留反斜杠 | ❌ **字符串里反斜杠转义不处理特殊字符**（`\$` 就是字面 `\$`） |
| `"反斜杠 \\"` | `\` | ✅ `\\` → `\`（唯一反斜杠转义） |
| `"# 井号 $ 美元 <标签> 反引号 \`"` | 全部字面量 | ✅ **`#` `$` `<` 反引号在字符串里全安全，无需转义** |

**结论**：code 模式字符串里 `#` `$` `<` `>` `[` `]` `*` `_` 全安全，只有 `\\` 需转义为 `\\`。

### 3. raw 反引号（markup 内原始文本）

```typst
`$ 和 # 和 [x] 和 *x*`
```
→ 全部字面量渲染 ✅（raw 块内特殊字符原始）

## 对任务 5（render_typst）的定案

**linotype 的 tex_escape 生成的是 `\textbf{...}` 等 LaTeX 标记；presswire 的 render_typst 若生成 markup 文本，用反斜杠转义；若生成 code 字符串字面量，几乎免转义。**

两条路径：
- **路径 A（markup 生成）**：`render_typst` 输出 `#let plates = (...)` + markup 内容，特殊字符用 `\` 转义——**与 linotype tex_escape 同思路**，但字符集不同（Typst: `$ # [ ] * _ < > { }` 需 `\`；LaTeX: `& % $ # _ { } ~ ^`）。
- **路径 B（code 字符串）**：输出 `#let body = "..."` 字符串字面量，**只需 `\\` 转义反斜杠**——更简单，但字符串内无法直接放结构化 content（如加粗/公式）。

**建议**：正文/标题等纯文本用**路径 B（code 字符串）**（几乎免转义，最稳）；需要富文本（加粗/公式/图片）的字段用**路径 A（markup + 反斜杠转义）**。转义函数：
```python
def typst_escape(s: str) -> str:
    # markup 模式: 反斜杠转义 Typst 特殊字符
    # 顺序: 先 \\ → \u{5C} 占位, 再特殊字符, 最后还原（仿 linotype 占位符血泪）
    s = s.replace("\\", "\x00")  # 反斜杠占位（防二次转义）
    for ch in "$#[]*_<>{}`":
        s = s.replace(ch, "\\" + ch)
    return s.replace("\x00", r"\u{5C}")  # 还原反斜杠（需 code 内或字符串内才解析）
```
⚠️ 注意：`\u{5C}` 还原反斜杠只在**字符串/code 内**解析——若还原到 markup 里需另想办法（测试 `\u{5C}` 在 markup 显示为字面）。**建议实际生成时用路径 B 为主，规避此坑。**

## 与 linotype 血泪的对应

- linotype「先转义特殊字符再处理 markdown」→ presswire 路径 B 天然规避（字符串无 markdown）。
- linotype「反斜杠占位符防二次转义」→ presswire 若走路径 A 同样需要（`\` 先占位）。
- **血泪 #35 反斜杠路径** → presswire 字符串路径天然安全。
